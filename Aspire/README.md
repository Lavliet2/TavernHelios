# TavernHelios Aspire AppHost

Этот проект использует .NET Aspire для оркестрации всех сервисов приложения TavernHelios.

## Запуск

Для запуска всего приложения через Aspire:

```powershell
dotnet run --project Aspire/TavernHelios.AppHost.csproj
```

После запуска откроется веб-интерфейс Aspire Dashboard, где вы сможете:
- Видеть все запущенные сервисы
- Просматривать логи в реальном времени
- Мониторить метрики и трассировку
- Управлять сервисами

## Что включено

### Базы данных и инфраструктура:
- **MongoDB** (mongoMenu, mongoLayout) - для MenuService и LayoutService
- **PostgreSQL** (postgresReservation, postgresAuth) - для ReservationService и AuthService
- **Redis** - для WeatherService
- **RabbitMQ** - для обмена сообщениями
- **ClickHouse** - для аналитики
- **Prometheus** - для метрик
- **Grafana** - для визуализации

### Сервисы приложения:
- **menuService** (порт 5064) - сервис меню
- **layoutService** (порт 5066) - сервис планировки
- **reservationService** (порт 5065) - сервис резерваций
- **authService** (порт 5067) - сервис аутентификации
- **weatherService** (порт 5069) - сервис погоды
- **server** (порт 5555) - главный сервер API
- **adminService** (порт 5068) - административный сервис

## Преимущества Aspire

1. **Единая точка запуска** - все сервисы запускаются одной командой
2. **Автоматическая конфигурация** - Aspire автоматически настраивает connection strings
3. **Service Discovery** - сервисы автоматически находят друг друга по именам
4. **Dashboard** - удобный веб-интерфейс для мониторинга
5. **Логи и метрики** - централизованный просмотр логов и метрик

## Примечания

- При запуске через Aspire все сервисы используют имена ресурсов для подключения друг к другу
- Базы данных автоматически создаются и настраиваются
- Порты могут отличаться от тех, что указаны в docker-compose (Aspire управляет портами автоматически)
